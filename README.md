# AI Chatbot

This is a simple AI chatbot built using Python and OpenAI's GPT API. The chatbot takes user input and generates responses using a pre-trained language model.

## Features
- Interactive chatbot interface
- Uses OpenAI's GPT model for natural language processing
- Easy to set up and run locally

## Requirements
- Python 3.7 or higher
- OpenAI API key
